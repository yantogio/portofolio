# Foto diri

Taruh foto di folder ini dengan nama berikut (format: .jpg, .jpeg, .png, .webp, atau .avif):

| Nama file      | Wajib? | Dipakai di                     |
|----------------|--------|--------------------------------|
| `portrait.jpg` | Ya     | Foto utama (hero)              |

- Ukuran asli bebas (foto HP 5 MB pun tidak apa-apa) — situs mengompres otomatis.
- Untuk mengganti foto: timpa file dengan nama yang sama.
- Saran: orientasi vertikal (portrait), cahaya cukup, latar bersih.
- Foto untuk tiap bab Pengalaman ditaruh di folder terpisah: `src/assets/journey/` (lihat README di sana).
