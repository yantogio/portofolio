# Foto bab Pengalaman (opsional)

Foto di folder ini otomatis muncul di bab yang tahunnya cocok. Satu bab boleh punya **satu foto atau lebih**.

## Cara memberi nama

**Cara 1: nama file diawali tahun**

```
journey/
├── 2025.jpg
├── 2025 (2).jpg
└── 2025-3.jpg
```

**Cara 2: satu folder per tahun** (nama file di dalamnya bebas)

```
journey/
└── 2025/
    ├── tim-facility.jpg
    └── presentasi.jpg
```

| Tahun  | Bab                                  |
|--------|--------------------------------------|
| `2015` | SMK Teknik Pemesinan                 |
| `2018` | Staf Logistik                        |
| `2020` | Sales Marketing, Telkom IndiHome     |
| `2022` | Kuliah Teknik Informatika            |
| `2025` | Software Developer Intern, PT Denso  |
| `2026` | Lulus                                |

## Cara tampil

- **Satu foto:** tampil biasa.
- **Dua foto atau lebih:** tampil sebagai tumpukan foto yang bergantian setiap 5 detik. Rotasi berhenti saat kursor berada di atasnya, saat tumpukan tidak terlihat di layar, dan bila pengunjung mematikan animasi di perangkatnya.
- **Urutan** mengikuti nama file: `2025.jpg` dulu, lalu `2025 (2).jpg`, `2025-3.jpg`, dan seterusnya.
- Klik foto untuk membukanya besar. Foto lain di bab yang sama bisa digeser dengan tombol ‹ › atau tombol panah keyboard.
- Format `.jpg`, `.png`, atau `.webp`. Ukuran asli bebas karena situs mengompres otomatis.
- Bab tanpa foto tetap tampil normal.

## Catatan

- Untuk foto di PT Denso, pastikan tidak ada informasi internal perusahaan yang terlihat.
- Untuk foto bersama orang lain, pastikan mereka tidak keberatan fotonya tampil di situs publik.
