# Sertifikat

1. Taruh PDF sertifikat di folder ini dengan nama yang tertulis di `certificates.yaml`:

   | File                                | Sertifikat                               |
   |-------------------------------------|------------------------------------------|
   | `database-design.pdf`               | Database Design — Oracle Academy         |
   | `pilkades-digital.pdf`              | Operator Teknis Pilkades Digital         |
   | `java-fundamentals.pdf`             | Java Fundamentals — Oracle Academy       |
   | `java-programming.pdf`              | Java Programming — Oracle Academy        |
   | `junior-network-administrator.pdf`  | Junior Network Administrator — VSGA      |
   | `it-essentials.pdf`                 | IT Essentials — Cisco                    |

2. Sertifikat baru: taruh PDF-nya, lalu tambahkan satu entri di `certificates.yaml`.
3. Gambar pratinjau (opsional): taruh gambarnya dan isi `thumb:` dengan nama file gambar.

Bila PDF belum ditaruh, sertifikat tetap tampil — hanya tanpa tombol "Lihat PDF".
