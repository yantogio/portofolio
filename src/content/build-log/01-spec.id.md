Sebelum satu baris kode ditulis, kebutuhan situs ini dirumuskan sebagai change OpenSpec bernama `build-portfolio-site`: proposal, delapan spec kapabilitas, desain teknis, dan 49 task.

Beberapa contoh aturan yang ditulis sebagai skenario yang bisa diuji:

- **Privasi.** Hasil build tidak boleh memuat nomor HP, tanggal lahir, agama, status pernikahan, atau alamat detail.
- **Tombol kondisional.** Tombol Live hanya muncul bila project punya link demo.
- **Bahasa.** Bahasa Indonesia di `/`, English di `/en`, dan pengalih bahasa tetap berada di halaman yang sama.
- **Satu tema.** Situs tidak berubah warna mengikuti mode gelap perangkat, sesuai keputusan pemilik.

Konten case study disusun dari README dan folder `openspec/` di masing-masing repositori, lalu saya review agar setiap angka sesuai sumbernya.
